# Angry Swine 😡

**Физическая игра в духе Angry Birds, где вместо птичек летят лица твоих друзей.**

Птички — фотки из папки `birds/` (Angry, Ivan, Очкарик, Sigma, Сматр): каждая обрезается в круг
прямо на canvas и летает из рогатки. Враги — свинки-копы вымышленного агентства **СВИНЬ**
с аксессуарами с оригинальных скриншотов: фуражка, каска, соломенная шляпа, ушки.

Фront и раскладки уровней повторяют скриншоты из `lvls/` (небо, облака, холмы, трава,
земляные насыпи, дерево/стекло/камень, HUD «Highscore/Score» и кнопка паузы).

## Как запустить

Дважды кликни **`run.bat`** — поднимется сервер и откроется браузер (http://localhost:8123).
Без bat: `npm start` или просто открыть `index.html`.

## Как играть

1. «▶ Играть» → выбери операцию (уровень).
2. Тяни друга с рогатки назад (мышью или пальцем), целься по пунктирной траектории, отпускай.
3. Уничтожь всех копов, пока друзья не кончились. Очки: коп +5000, блок +500, оставшийся друг +10000. До 3 звёзд.
4. Кнопка «❚❚» слева сверху — пауза (продолжить / заново / меню).

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | экраны: меню (состав друзей), выбор уровня, игра, пауза/победа/поражение |
| `styles.css` | оформление, HUD в стиле оригинала |
| `birds/*.webp` | фотки друзей — используются как лица птичек |
| `lvls/*.{webp,jpg,png}` | референс-скриншоты уровней |
| `js/birds.js` | загрузка фоток, круглый кроп спрайтов, ротация в очереди |
| `js/levels.js` | 4 уровня по раскладке скриншотов + `terrain` (насыпи), конструктор башен |
| `js/game.js` | движок на **Matter.js**: рогатка, урон по HP, разрушения, взрывы TNT, фон/рендер, пауза |
| `js/main.js` | UI, прогресс/рекорды (localStorage), пауза, состав |
| `vendor/matter.min.js` | физический движок (vendored) |

## Важно про арт и названия

Игра — фан-оммаж: механика похожа, но весь код и графика — свои (canvas), ассеты
Rovio/Angry Birds не используются. «СВИНЬ» — вымышленное агентство вместо реального
INTERPOL (товарный знак). Фотки друзей лежат локально и никуда не отправляются.

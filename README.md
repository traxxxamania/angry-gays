# Angry Swine 😡🐦

**Жаждущие возмездия** — оригинальная физическая игра в духе Angry Birds, где вместо птичек летит ТВОЁ ЛИЦО.

Лицо загружается через камеру или фото, обрезается в круг и превращается в мультяшную птичку (клюв, хвост, хохолок).
Враги — копы вымышленного агентства **СВИНЬ** (пародийные «интерпол-свинки»). Снеси все их посты!

## Как запустить

Просто открой `index.html` в браузере. Либо локальный сервер:

```
npm start
```

и зайди на http://localhost:8123

## Как играть

1. Нажми «📸 Моё лицо в игре» — сфоткайся или загрузи фото, выровняй лицо в круге, сохрани.
2. «▶ Играть» → выбери операцию (уровень).
3. Тяни птицу с рогатки назад (мышью или пальцем), целься по пунктирной траектории, отпускай.
4. Уничтожь всех копов, пока не кончились птицы. Очки за копов (+5000), блоки (+500) и оставшихся птиц (+10000). До 3 звёзд за уровень.

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | экраны: меню, выбор уровня, игра, модалка лица |
| `styles.css` | оформление |
| `js/face.js` | захват лица (камера/фото), круглая обрезка, сборка спрайта птицы, localStorage |
| `js/levels.js` | 4 уровня, конструктор башен `column/slab/crate` (материалы: wood, ice, stone, powder) |
| `js/game.js` | движок на **Matter.js**: рогатка, урон по HP, разрушения, взрывы TNT, частицы, рендер на canvas |
| `js/main.js` | UI-обвязка, прогресс/звёзды (localStorage), старт уровней |
| `vendor/matter.min.js` | физический движок (vendored) |

## Что уже работает

- ✅ Физика: рогатка с затяжкой, прогноз траектории, разрушаемые блоки (дерево/лёд/камень), взрывные ящики с радиусом поражения
- ✅ Враги-копы: HP, урон от птицы и от падающих блоков, гибель от падения на землю
- ✅ Загрузка лица: камера (getUserMedia) или фото + круглый кроппер с зумом; спрайт птички композится на canvas и хранится в localStorage
- ✅ 4 уровня, звёзды, рекорды, последовательная разблокировка
- ✅ Победа/поражение, рестарт, бонус за оставшихся птиц, тряска экрана, частицы

## Идеи на будущее

- Ещё уровни + песочные/резиновые материалы
- Звук (WebAudio, без файлов)
- Таблица рекордов (вот тут и понадобится `back-end` ветка/API)
- Улучшение маски лица: автоопределение лица (face-api.js) и овальная обрезка

## Важно про арт и названия

Игра — оммаж: механика похожа, но весь код и арт оригинальные (canvas-графика), ассеты Angry Birds не используются.
«СВИНЬ» — вымышленное агентство, чтобы не нарушать товарный знак INTERPOL.

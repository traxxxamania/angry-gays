# Angry Swine 😡

**Физическая игра в духе Angry Birds, где вместо птичек летят лица твоих друзей.**

Птички — фотки из `public/birds/` (Angry, Ivan, Очкарик, Sigma, Сматр): каждая обрезается
в круг прямо в браузере и летает из рогатки. Враги — свинки-копы вымышленного агентства
**СВИНЬ** с аксессуарами с оригинальных скриншотов: фуражка, каска, соломенная шляпа, ушки.

Front и раскладки уровней повторяют скриншоты из `lvls/` (небо, облака, холмы, трава,
земляные насыпи, дерево/стекло/камень, HUD «Highscore/Score» и кнопка паузы).

## Стек

**React 19 + Vite + Matter.js.** Вся UI-часть (меню, выбор уровня, HUD, оверлеи) — React-компоненты,
игра (физика + canvas-рендер) — фреймворк-независимый класс `GameEngine`. Сборки/транзайла
JSX нет — только `vite`. Прогресс и рекорды — `localStorage`.

## Как запустить

Дважды кликни **`run.bat`** — при первом запуске поставит зависимости, поднимет Vite
и сам откроет браузер на http://localhost:8123. Вручную:

```
npm install
npm run dev      # сервер разработки + HMR
npm run build    # прод-сборка в dist/
npm run preview  # локальный предпросмотр прод-сборки
```

## Как играть

1. «▶ Играть» → выбери операцию (уровень).
2. Тяни друга с рогатки назад (мышью или пальцем), целься по пунктирной траектории, отпускай.
3. Уничтожь всех копов, пока друзья не кончились. Очки: коп +5000, блок +500, оставшийся друг +10000. До 3 звёзд.
4. Кнопка «❚» слева сверху — пауза (продолжить / заново / к уровням).

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | точка входа Vite |
| `vite.config.js` | конфиг Vite (react-плагин, порт 8123, strictPort) |
| `src/main.jsx` | монтирование React-приложения |
| `src/App.jsx` | роутинг экранов (меню / уровни / игра) через state |
| `src/styles.css` | оформление |
| `src/progress.js` | прогресс и рекорды (localStorage) |
| `src/components/` | `MenuScreen` (состав друзей), `LevelSelect`, `GameScreen` (canvas + HUD + пауза/победа/поражение) |
| `src/game/engine.js` | класс `GameEngine` — Matter.js: рогатка, урон по HP, разрушения, TNT, фон/рендер |
| `src/game/birds.js` | фотки друзей → круглые спрайты птичек |
| `src/game/levels.js` | 4 уровня по раскладке скриншотов, `terrain` (насыпи), конструктор башен |
| `public/birds/*.webp` | фото друзей |
| `lvls/*` | референс-скриншоты уровней |

## Важно про арт и названия

Игра — фан-оммаж: механика похожа, но весь код и графика — свои (canvas), ассеты
Rovio/Angry Birds не используются. «СВИНЬ» — вымышленное агентство вместо реального
INTERPOL (товарный знак). Фотки друзей лежат локально и никуда не отправляются.
